Referencia HTML & CSS

Propiedades · Categorías · Funciones

Clasificación Propiedad Categoría Función
Contenido Nuevo <main> HTML · Semántica Define el bloque de contenido principal y exclusivo del documento.
Contenido Nuevo <button> HTML · Interacción Crea elementos cliqueables que ejecutan acciones.
Contenido Nuevo <address> HTML · Semántica Envuelve información de contacto o direcciones físicas.
Contenido Nuevo <em> HTML · Semántica Aporta énfasis estructural e itálica al texto.
Contenido Nuevo <figure> HTML · Semántica Agrupa contenido gráfico (imágenes) aislando su contexto visual.
Contenido Nuevo <svg>, <path>, <rect>, <circle> HTML · Gráficos Dibuja vectores e íconos matemáticamente directo en el código.
Contenido Nuevo <script> HTML · Lógica Inyecta y ejecuta interactividad mediante JavaScript.
Contenido Nuevo property="og:title/description" HTML · Metadatos Controla la previsualización al compartir el enlace en redes sociales.
Contenido Nuevo rel="preconnect", crossorigin HTML · Red Acelera la conexión a servidores externos (ej. Google Fonts).
Contenido Nuevo loading="lazy" / "eager" HTML · Rendimiento Retrasa o prioriza la carga de imágenes para optimizar la velocidad.
Contenido Nuevo aria-* (label, hidden, live) HTML · Accesibilidad Traduce la interfaz visual para lectores de pantalla de usuarios no videntes.
Contenido Nuevo :root, var(--nombre) CSS · Variables Almacena colores y tamaños centralizados para reutilizarlos en todo el CSS.
Contenido Nuevo clamp() CSS · Matemáticas Escala tipografías dinámicamente entre un tamaño mínimo y máximo.
Contenido Nuevo Flexbox (display: flex, gap, etc.) CSS · Layout Distribuye y alinea elementos en una sola dimensión (fila o columna).
Contenido Nuevo CSS Grid (display: grid) CSS · Layout Construye cuadrículas estructurales complejas en dos dimensiones.
Contenido Nuevo display: block / none CSS · Comportamiento Define si un elemento ocupa todo el ancho o se oculta del documento.
Contenido Nuevo position: relative/absolute/fixed CSS · Posicionamiento Extrae elementos del flujo (fija el menú al scroll o superpone sellos).
Contenido Nuevo top, left, right, bottom, inset CSS · Posicionamiento Coordenadas exactas para mover elementos posicionados absolutamente.
Contenido Nuevo z-index CSS · Posicionamiento Define el orden de las capas (qué elemento va encima de otro).
Contenido Nuevo linear-/radial-gradient() CSS · Estética Genera transiciones suaves entre colores sin usar imágenes externas.
Contenido Nuevo backdrop-filter: blur() CSS · Estética Efecto "Glassmorphism" que desenfoca el fondo detrás de un elemento.
Contenido Nuevo background-clip: text CSS · Estética Aplica un fondo o degradado directamente al relleno del texto.
Contenido Nuevo opacity CSS · Estética Controla el nivel de transparencia de un elemento completo.
Contenido Nuevo overflow: hidden CSS · Estética Recorta y oculta cualquier contenido que se desborde de su caja.
Contenido Nuevo transition CSS · Motion UI Interpola cambios de estado (ej. color al hacer hover) de forma fluida.
Contenido Nuevo transform (scale, translate) CSS · Motion UI Escala, mueve o rota elementos sin alterar la maqueta de alrededor.
Contenido Nuevo @keyframes, animation CSS · Motion UI Define y ejecuta secuencias de animación complejas fotograma a fotograma.
Contenido Nuevo margin-/padding-inline/block CSS · Lógico Márgenes y rellenos adaptativos basados en la dirección del texto.
Contenido Nuevo aspect-ratio CSS · Utilidades Obliga a una caja a mantener una proporción matemática (ej. 16/9).
Contenido Nuevo object-fit: cover CSS · Utilidades Hace que una imagen llene su caja perfectamente sin estirarse.
Contenido Nuevo pointer-events CSS · Utilidades Controla si un elemento reacciona o es "traspasado" por el clic del mouse.
Contenido Nuevo visibility CSS · Utilidades Oculta un elemento visualmente, pero deja su espacio vacío intacto.
Contenido Nuevo white-space: nowrap CSS · Utilidades Fuerza a una línea de texto a no saltar al siguiente renglón.
Contenido Nuevo scroll-behavior: smooth CSS · Utilidades Hace que la navegación por anclas se deslice suavemente.
Contenido Nuevo cursor: pointer CSS · Utilidades Transforma el puntero en una mano para indicar interactividad.
Contenido Nuevo list-style: none CSS · Utilidades Elimina los puntos o números por defecto de las listas HTML.
Contenido Nuevo @media (max-width: Xpx) CSS · Responsivo Aplica reglas condicionales para adaptar el diseño a móviles o tablets.
Contenido Nuevo @media (prefers-reduced-motion) CSS · Accesibilidad Desactiva animaciones si el sistema operativo del usuario lo solicita.
